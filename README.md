# Grok Agent Skill

`grok` is a portable Agent Skill for fast, resumable learning branches during coding, research, writing, or other work.

The portable skill source lives in [`skills/grok`](skills/grok). Product-specific manifests live in [`.codex-plugin`](.codex-plugin) and [`.claude-plugin`](.claude-plugin).

## Codex

Package `skills/grok` with the Codex plugin manifest in `.codex-plugin/plugin.json`.

## Claude Code

Package `skills/grok` with the Claude plugin manifest in `.claude-plugin/plugin.json`.
